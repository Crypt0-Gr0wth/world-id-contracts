# 3. Nullifiers et anti-double usage

Le nullifier est une valeur dérivée du contexte et de l’identité prouvée. Le contrat peut marquer ce nullifier comme utilisé afin d’empêcher une seconde action tout en conservant l’anonymat de l’utilisateur.

Le choix du scope est donc déterminant : un scope trop large bloque des usages légitimes, un scope trop étroit peut permettre plusieurs participations là où une seule est attendue.
