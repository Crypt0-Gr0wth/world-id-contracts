# 2. Vérification des preuves

Une preuve World ID encode un engagement, un signal d’action et des éléments permettant de démontrer l’appartenance à un groupe. Le vérificateur contrôle la preuve cryptographique, la racine connue et le contexte de l’application.

Le signal d’action lie une preuve à son usage prévu. Cette liaison évite qu’une même preuve soit réutilisée dans un autre contexte sans autorisation.
